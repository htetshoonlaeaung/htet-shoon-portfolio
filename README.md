# Htet Shoon Lae Aung — Portfolio

An editorial React + TypeScript portfolio built with Vite.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Update the portfolio

- Edit project descriptions, awards, hackathons, photo gallery entries, skills, community activities, recognition and certifications in `src/content.ts`.
- Update the hero and section copy, profile links, email and CV placeholder in `src/App.tsx`.
- Add real image files under `public/images/`; assign paths in `profileImage`, a project's optional `image` field, or a gallery item's optional `image` field in `src/content.ts`. The labeled placeholders switch to the supplied photo automatically.
- The project modal includes ready-to-fill fields for overview, problem, solution, role, team, technologies, features, results and links.

No personal photos, contact details, rankings or project technical claims have been fabricated. Unprovided details are visibly marked for later editing.
